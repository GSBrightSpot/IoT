ENTREGA

A solução desenvolvida deverá obrigatoriamente utilizar Visão Computacional com processamento de vídeo via webcam ou video, independentemente do tema escolhido pelo grupo.

Os alunos deverão utilizar bibliotecas apresentadas em sala, como:

OpenCV
MediaPipe
Etc.

A solução deve:

Capturar vídeo em tempo real;
Realizar alguma inferência visual (detecção, reconhecimento, rastreamento, OCR, pose, etc.);
Demonstrar uma aplicação prática dentro do contexto da GS.

O desenvolvimento deverá ser feito obrigatoriamente em Python.

CRITÉRIOS DE AVALIAÇÃO (100 pontos)
1. Vídeo da Solução (50 pontos)

O vídeo deverá:

Explicar rapidamente o problema e a proposta;
Demonstrar o sistema funcionando;

Também será avaliado:

Clareza da explicação;
Funcionamento da inferência visual;
Estabilidade básica da solução em diferentes condições (luz, movimento, distância, etc.).

2. Código Python (30 pontos)

Será avaliado:

Organização do código;
Funcionamento da solução;
Uso correto das bibliotecas;
Estrutura do pipeline de Visão Computacional.

Obrigatório:
Captura de vídeo em tempo real;
Código enviado funcionando.

3. Repositório GitHub (20 pontos)

O projeto deverá ser disponibilizado em um repositório público no GitHub.

O repositório deverá conter:

Código-fonte;
requirements
README simples contendo:
descrição da solução;
bibliotecas utilizadas;
instruções básicas de execução;
nomes dos integrantes.

ENTREGA
Apenas um integrante do grupo deverá enviar a entrega.
O vídeo pode ser enviado via YouTube (não listado).
O repositório deverá permanecer público até o término das correções.
